# Marit Silva Gebhardt — persönliche Website

Zweisprachiger statischer Onepager mit separater Portfolio-Seite, vorbereitet für GitHub Pages und die Domain `maritsilvagebhardt.com`.

## Manuell über GitHub Pages veröffentlichen

1. Ein öffentliches GitHub-Repository für die Website anlegen.
2. Den vollständigen Inhalt dieses Ordners in die oberste Ebene des Repositorys hochladen.
3. Unter **Settings → Pages** die Quelle **Deploy from a branch**, den Branch **main** und den Ordner **/(root)** auswählen.
4. Unter **Custom domain** `maritsilvagebhardt.com` eintragen.
5. Beim Domainanbieter die von GitHub angezeigten DNS-Einträge hinterlegen.
6. Nach erfolgreicher Prüfung **Enforce HTTPS** aktivieren.

Das Kontaktformular öffnet das E-Mail-Programm des Besuchers und bereitet eine Nachricht an `mette.tentary@outlook.de` vor. Die Website speichert keine Formulardaten.

Vor der Veröffentlichung muss in `impressum.html` und `datenschutz.html` noch die vollständige ladungsfähige Anschrift ergänzt und die Rechtstexte abschließend geprüft werden.
